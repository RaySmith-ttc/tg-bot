# Пример использования локаций

Пример использования локаций в боте

---

При использовании команды `/form` пользователь проходит абстракную форму заполняя данные, переходя от одного запроса
данных к другому, перемещаясь по локациям.

Основной функционал:
- Использование базы данных H2 для хранения и обновление локаций пользователей
- Переходы между локациями и возврат к предыдущей
- В каждой локации свой набор обработчиков событий, который может отличаться от других локаций

### Run
Необходимые переменные окружения:
- `TG_BOT_TOKEN` - токен бота

```bash
./gradlew run
```
